> ⭐⭐⭐⭐⭐**注意：**
>
> * `sorted()` 返回新列表，`sort()` 直接修改原列表。

> Python 的**列表推导式**
>
> * 用于简洁地生成列表
>
> * 基本格式:
>
>   ~~~python
>   [表达式 for 变量 in 可迭代对象 if 条件]
>   ~~~
>
> 
>
> **你的代码：**
>
> ```python
> new_list = [i**2 for i in list4 if i % 3 == 0 or i % 5 == 0]
> ```
>
> **含义是：**
>
> 1. 遍历 `list4` 中的每个元素，暂时叫 `i`
> 2. 判断 `i` 是否能被 3 或 5 整除
> 3. 如果满足条件，就把 `i**2` 放入新列表
>
> **等价于普通写法：**
>
> ```python
> new_list = []
> 
> for i in list4:
>     if i % 3 == 0 or i % 5 == 0:
>         new_list.append(i ** 2)
> ```
>
> **运行结果：**
>
> ```python
> [9, 25, 36,  ಒ]
> ```
>
> **实际完整结果为：**
>
> ```python
> [9, 25, 36, 100, 144, 225, 324, 400, 441, 576, 625, 729, 900]
> ```



> 注意：
>
> * Python 里逻辑“或”要用 `or`，不能用 `||`。
