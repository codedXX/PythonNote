# Python 核心语法：数据存储与运算

> **学习目标：** 用变量表达业务数据，完成输入、计算、判断和清晰输出。

## 字面量、变量与命名

字面量是代码中的固定值，例如 `100`、`3.14`、`"Python"`、`True`；变量是保存数据的名称。`=` 表示把右侧的值绑定给左侧变量，变量之后可以重新赋值。

```python
name = "Alice"
score = 95
score = score + 5
```

> **重点：** 标识符只能由字母、数字、下划线组成，不能以数字开头，也不能使用关键字。变量和函数推荐使用 `snake_case`。

## 数据类型与输入输出

常见基础类型为 `int`、`float`、`str`、`bool`，可用 `type(value)` 查看类型。`input()` 的返回值始终是字符串，参与数值计算前必须转换。

```python
age = int(input("年龄："))
height = float(input("身高："))
print(f"明年年龄：{age + 1}")
```

字符串推荐使用 f-string 格式化：`f"总价：{price:.2f}"`。这比 `+` 拼接更适合混合文本和数值。



> **height = float(input("身高："))这是什么意思，对输入的内容转为float类型吗？**
>
> * 对，执行过程是：
>   1. `input("身高：")` 显示提示并接收输入。
>   2. `input()` 返回的内容`始终是`字符串 `str`。
>   3. `float(...)` 把这个字符串转换成浮点数。
>   4. 将结果保存到变量 `height`。
>
> 
>
> ⭐️**f的意思是什么？**
>
> * 在字符串前加 `f` 或 `F`，就可以在 `{}` 中嵌入 Python 表达式，并把表达式的结果格式化到字符串中。
>   * 加 `f` 后，`{}` 里的内容会被计算并替换；不加 `f`，它们只是普通字符。

## 运算与条件

算术运算符：`+ - * / // % **`。其中 `/` 是浮点除法，`//` 是整除，`%` 常用于判断倍数和奇偶。比较运算符 `== != > >= < <=` 的结果为布尔值；用 `and`、`or`、`not` 组合条件。

> **重点：** 比较相等使用 `==`，不是 `=`；复杂条件要用括号明确优先级。输入转换前应考虑非法内容，例如 `int("3.5")` 会抛出异常。
