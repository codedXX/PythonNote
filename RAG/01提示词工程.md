### 修改接入地址和模型名称以调用 Ollama

<!-- PDF 第 26 页 -->

使用代码调用Ollama的本地模型还是很简单的，只需要将原有代码进行简单改动即可。

~~~~
from openai import OpenAI
client = OpenAI(
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
)
completion = client.chat.completions.create(
    model="deepseek-v3",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "你是谁，能做什么？"},
    ],
    stream=True
)
for chunk in completion:
    print(chunk.choices[0].delta.content, end="", flush=True)
 
~~~~

- 将base\_url改为：http://localhost:11434/v1

- 将model改为对应本地模型名称，如：qwen3:4b

### 语言模型 (Language Model, LM)

<!-- PDF 第 41 页 -->

语言模型（Language Model）旨在建模词汇序列的生成概率，提升机器的语言智能水平，使机器能够模拟人
类说话、写作的模式进行自动文本输出。

通俗理解: 用来计算一个句子的概率的模型，也就是判断一句话是否是人话的概率.

标准定义：对于某个句子序列, 如S = {W1, W2, W3, …, Wn}, 语言模型就是计算该序列发生的概率, 即P(S).
如果给定的词序列符合语用习惯, 则给出高概率, 否则给出低概率.

### Zero-shot思想

<!-- PDF 第 65 页 -->

Zero-shot学习（Zero-shot Learning）是指在训练阶段不存在与测试阶段完全相同的类别，但是模型可以使用训练过的知识
来推广到测试集中的新类别上。

这种能力被称为“零样本”学习，因为模型在训练时从未见过测试集中的新类别，在模型训练和提示词优化中均有体现。

def clean_response(response: str):
    """
    后处理模型输出。
    Args:
        response (str): _description_
    """
    if '```json' in response:
        res = re.findall(r'```json(.*?)```', response)
        if len(res) and res[0]:
            response = res[0]
        response.replace('、', ',')
    try:
        return json.loads(response)
    except:
        return response
 
~~~~
